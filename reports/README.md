# reports/

Generated by the pipelines (`make pipeline` / `make pipeline-local` / the Airflow DAGs) on the
default dataset (seed 42, SMALL preset). They are committed so the numbers quoted in the README
and docs can be checked; re-running the pipeline regenerates them deterministically.

| File | Produced by |
|---|---|
| fraud_model_comparison.{md,json} | `python -m ml train-fraud` - XGBoost vs Isolation Forest vs behavioural baseline |
| fraud_xgb_metrics.json, fraud_xgb_shap_importance.json | supervised fraud model: test metrics, imbalance experiments, calibration, SHAP |
| ato_xgb_metrics.json | account-takeover model |
| threshold_analysis.{md,json} | `python -m ml.fraud_detection.thresholds` - decision thresholds for configs/policy.yaml |
| graph_analysis.json | graph analytics vs hidden mule ground truth |
| segmentation.json | K-Means vs HDBSCAN, segment profiles, persona mix |
| churn.json | churn model, snapshots, calibration, recency baseline |
| monitoring_report.json | `python -m monitoring` - PSI drift and weekly realised performance |
| data_quality_synthetic.{md,json} | DQ gate on the source extracts |
| data_quality_bronze.{md,json} | DQ on the Spark bronze zone after a streaming replay (duplicates are expected there) |
